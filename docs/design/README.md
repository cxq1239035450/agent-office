# 办公楼设计实现

参考图：office-concept.png。实现截图：office-implemented.png。

## 设计系统

暖白画布 #faf6ef、面板 #fffaf4、深蓝文字 #292b3e、绿色强调 #268d7a；Segoe UI / Microsoft YaHei 字体，8px 圆角按钮，细线图标。移动端转为纵向布局。

## 设计对照

| 设计点 | 当前实现 |
| --- | --- |
| 暖白、深蓝、绿色视觉 | 全局界面与管理表单已统一 |
| 左导航、中大楼、右详情、底指令 | 已实现；小屏纵向排列 |
| 新建工作区增加楼层 | 已接真实 API，按创建时间排列 |
| 13 个职业人物 | 透明图集，支持选择形象，保留角色 ID |
| 共用电梯井与选层高亮 | 已实现；电梯表现选层，不执行寻路 |
| 真实状态与气泡 | 接 WebSocket，演示动画隔离为只读预览 |
| 房间与办公姿态 | 目前复用底图与主题色调，尚未实现概念中独立家具和坐姿 |
| 任务与交付列表 | 显示实际事件和文件，未伪造概念中的交付物和进度 |

文案差异：CLI「已连接」改为「可用」，避免把程序检测当作认证成功；任务中心改为任务记录；增加设计预览提示。浏览器创建表单使用手动目录路径。结构与色彩已落地，人物姿态、专属布景和完整行走动画仍有差距，不宣称逐像素还原。

## 素材

内置 ImageGen 生成（2026-11-24）：office-floor.png 是横向暖木像素办公室，四个桌子、窗户、植物、吊灯，无人物及 UI 文本；team-atlas.png 是透明 5×3 图集，13 位职业人物，最后两格为空，顺序对应 CHARACTER_PRESETS。生产素材独立生成，不是裁切概念图中的 UI。

## 验证与范围

生产构建、全仓类型检查、楼层排序和输入不变性测试通过。内置浏览器验证真实工作区创建、选层与预览；独立 Chromium 验证新增剪辑师、预览禁止派发、390px 布局无页面横向溢出、创建表单可见，无页面异常。

未运行真实模型任务、外部 MCP 或完整人工审批。动画是状态驱动的 CSS 动作，未实现逐帧行走、A* 寻路与跨层乘梯。
